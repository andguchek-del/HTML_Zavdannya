Призначення HTML-таблиць

HTML-таблиці використовуються для впорядкованого подання інформації у вигляді рядків і стовпців. За допомогою CSS можна налаштувати їхні кольори, рамки, відступи та ефекти наведення.

Основні HTML-теги таблиць

Тег Призначення Приклад використання
<table> Створює таблицю Контейнер усіх рядків
<tr> Створює рядок Групує комірки
<th> Заголовок стовпця Назва поля
<td> Звичайна комірка Текст або число
<thead> Група заголовків Верхня частина таблиці
<tbody> Основний вміст Рядки з даними

Висновок

HTML відповідає за структуру таблиці, а CSS — за її зовнішній вигляд. Правильне оформлення робить інформацію зрозумілою та зручною для читання.
