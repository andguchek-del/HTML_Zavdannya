Що таке CSS?

CSS — це мова стилів, яка використовується для оформлення HTML-документів. За її допомогою можна змінювати кольори, шрифти, відступи, розміри елементів та їхнє розташування.

Основні можливості CSS

  • Зміна кольору тексту та фону.
  • Налаштування шрифтів і розмірів.
  • Створення карток і кнопок.
  • Додавання рамок, тіней і заокруглень.
  • Адаптація сторінки під різні екрани.
